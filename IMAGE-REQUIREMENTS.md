# Image Requirements for Fit 4 Existence Website

This document provides a comprehensive guide to all the images needed for the Fit 4 Existence website.

## Directory Structure

All images should be placed in the appropriate subdirectories within the `/public/images/` folder:

```
/public/images/
├── about/        # Images for About section
├── doctors/      # Doctor profile images
├── hero/         # Hero section banner images
├── icons/        # Service icons (SVG format)
├── services/     # Service-specific images
└── testimonials/ # Patient testimonial avatars
```

## Image Optimization

Before uploading any images to the website, please optimize them to reduce file size without compromising quality. You can use tools like:

1. [TinyPNG](https://tinypng.com/) - Free online tool for compressing PNG and JPG images
2. [Squoosh](https://squoosh.app/) - Advanced image compression tool
3. [SVGOMG](https://jakearchibald.github.io/svgomg/) - For optimizing SVG files

## Important Notes

1. Use descriptive filenames with lowercase letters and hyphens (e.g., "knee-therapy.jpg")
2. Ensure all images are properly compressed to improve website loading speed
3. For photos with people, ensure you have proper permission to use them
4. Keep backup copies of original images before compression
5. Test the website after adding images to ensure they display correctly on different screen sizes
