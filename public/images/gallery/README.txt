- treatment-1.jpg

(You can add more by updating the galleryImages array in app/gallery/page.js)

IMAGE SPECIFICATIONS:
- Format: JPG or PNG
- Size: 800px × 800px (square format recommended)
- Quality: High resolution but optimized for web (file size <300KB)
- Content: Professional photos showing treatment sessions

IMPORTANT NOTES:
1. Ensure you have proper consent from patients before using their photos
2. Maintain patient privacy - avoid showing faces clearly if not consented
3. Focus on treatment techniques and equipment
4. Use well-lit, professional-looking photos
5. Compress images to improve website loading speed

HOW TO ADD MORE IMAGES:
1. Add your image files to this directory
2. Open app/gallery/page.js
3. Add new entries to the galleryImages array following the existing format
