IMAGE REQUIREMENTS FOR DOCTOR PROFILES

1. File Format:
   - Use JPG, JPEG, or PNG formats for best compatibility
   - SVG is not recommended for photos but can be used for icons

2. File Names:
   - Use the naming convention shown in the DoctorProfilesSection.jsx file
   - For example: "prince-raj.jpg", "rohit-kumar.jpg"
   - Use lowercase letters and hyphens instead of spaces

3. Image Dimensions:
   - Recommended size: 600px × 800px (portrait orientation)
   - Minimum width: 400px
   - Keep all doctor images at the same aspect ratio for consistency

4. Image Optimization:
   - Compress your images to reduce file size (aim for under 200KB per image)
   - You can use tools like TinyPNG (https://tinypng.com/) or Squoosh (https://squoosh.app/)

5. Image Content:
   - Professional headshots or half-body shots work best
   - Use consistent lighting and background for all doctor images
   - Ensure the face is clearly visible and well-lit

6. Where to Place Images:
   - All doctor profile images should be placed in this directory:
     /public/images/doctors/

7. Example:
   - If your doctor's name is "Dr. Prince Raj", save the image as:
     /public/images/doctors/prince-raj.jpg
   - Then reference it in the code as:
     image: '/images/doctors/prince-raj.jpg'
