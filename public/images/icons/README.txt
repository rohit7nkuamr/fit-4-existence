ICON REQUIREMENTS FOR SERVICES

This directory should contain SVG icons for all services offered by Fit 4 Existence.

REQUIRED ICONS:
1. knee.svg - Icon for knee pain treatment
2. back.svg - Icon for back pain treatment
3. paralysis.svg - Icon for paralysis rehabilitation
4. cervical.svg - Icon for cervical pain treatment
5. cupping.svg - Icon for cupping therapy
6. sciatica.svg - Icon for sciatica treatment
7. shoulder.svg - Icon for shoulder pain treatment
8. muscle.svg - Icon for muscle pain treatment

ICON SPECIFICATIONS:
- Format: SVG is preferred for scalability
- Size: Icons should be designed on a 24x24 grid
- Style: Use a consistent style across all icons
- Color: Icons should be single-color (the color is applied via CSS)
- Stroke width: Use consistent stroke width (recommended: 2px)

WHERE TO FIND ICONS:
1. Create custom icons using vector software like Adobe Illustrator
2. Use free icon libraries like:
   - Feather Icons: https://feathericons.com/
   - Heroicons: https://heroicons.com/
   - Font Awesome: https://fontawesome.com/

HOW TO SAVE ICONS:
1. Download or export the icon as SVG
2. Name the file according to the naming convention above
3. Place the file in this directory

EXAMPLE SVG STRUCTURE:
```svg
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <!-- Icon paths go here -->
</svg>
```

The "currentColor" value for the stroke attribute allows the icon color to be controlled via CSS.
